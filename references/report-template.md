## 三、取证逻辑（回答"凭什么这样判断"）

1. **访问量定位**：基线 <N> 条/天，事件日 <M> 条，突增 <倍数> 倍。
2. **频率定位**：事件日流量 <比例> 来自单一 IP `<IP>`，其余为正常流量。
3. **行为特征**：该 IP 只访问高价值路径（<列举>），不加载静态资源，与正常浏览流量明显不同。
4. **身份区分**：`<IP_A>` 能用 <账号> 登录 manager（200），`<IP_B>` 多次尝试均 401 并转 SSH 爆破，判定后者为攻击者。
5. **交叉验证**：木马落盘时间 <T1> → 容器编译 <T2> → 部署日志 <T3> → 首次访问 200 <T4>，四段自洽。

## 五、处置建议

1. 清除：删除木马文件与 war、清理 `work/Catalina/localhost/<app>/` 编译产物。
2. 账号：删除后门账号，核查 `/etc/shadow`、`/etc/sudoers`、`authorized_keys`、crontab 是否仍有持久化。
3. 口令：重置受影响账号口令，禁用 root 远程登录，部署 fail2ban。
4. 收敛：删除或限制 Tomcat Manager / 后台访问，改为强口令 + 来源 IP 白名单。
5. 复核：全盘排查其他 `*.jsp/jspx/war` 落地文件与内存马特征。
